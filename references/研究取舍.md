# 研究取舍

在选题卡住、实验成本升高或结果难解释时使用。

| 遇到的情况 | 如何继续 |
| --- | --- |
| 方向很宽 | 从一篇论文或一个日志里提取可观察现象，做一个小检查。把检查暴露的问题写成候选主张 |
| 点子看起来简单 | 先问它能否区分两种解释，再用查新检查差异。可做的简单对照适合验证机制 |
| 有多个可做题目 | 选一个最可能改变理解且能快速检验的主张。其他候选留在记录里，等现有证据改变优先级 |
| 查新发现相同做法 | 保留作基线，把差异压到一个新设置、一种机制解释或一个未做的消融 |
| 条件不够跑主实验 | 先缩小模型、数据或任务范围，估算单次迭代成本。若缩小后指标失去意义，重新界定问题 |
| 日常实验快，放大很贵 | 用小实验排除主要替代解释。只把能检验外推范围的少量条件放大 |
| 读不懂某个结果 | 先用自己的话写预期机制，再找实际结果与机制冲突的位置。以能区分解释的对照继续 |
| 有多条工作线 | 让主实验、竞争解释、消融和查新各自有明确问题，共用同一条主张 |
| 稿件已经成形但论点过宽 | 给每条主要主张找对应证据。选择补上会改变判断的对照，或收窄主张到已测设置 |
