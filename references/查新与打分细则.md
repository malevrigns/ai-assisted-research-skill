# 查新与打分细则

## 检索和核对

1. 把点子拆成「任务、关键操作、被测现象」三个词组。分别检索同义词、相邻领域术语，以及最接近方法的名称。
2. 按领域选择可用渠道。例如在 arXiv 找预印本，在 OpenReview 或官方论文集核对发表状态，沿引用链补查早期工作与后续改进。记录实际使用的渠道、检索词、覆盖日期和检索日期。
3. 打开最接近的全文，定位方法、实验、消融和附录。逐篇记录章节或图表位置、与当前点子的差异、是否已经覆盖关键操作。只打开摘要的论文只用于初步定位。找不到全文时记录缺口，必要时降低查新结论的确定性。
4. 把实质差异写成可检验的预测。例如「离线评估已有结果，在线反馈下是否仍有效需要验证」。已覆盖的做法可作为基线，前提是能提出具体的新问题。

| 查新结论 | 判定 |
| --- | --- |
| 已覆盖 | 已核对的工作在相同或足够相近的设置下完成了关键操作并报告结果 |
| 部分覆盖 | 关键操作或设置重合，剩余差异可明确描述 |
| 当前检索未发现 | 在已报告的检索范围和已核对全文中没有找到同样的操作和设置 |
| 证据不足 | 检索条件、渠道或全文访问受限，现有信息不足以比较 |

| 最接近工作（链接） | 日期与发表状态 | 阅读深度及位置 | 重合点 | 差异与可检验的缺口 |
| --- | --- | --- | --- | --- |
| | | 全文 / 摘要 / 无法访问 | | |

如果用户关心机构归属，按论文署名或作者主页核实。所用模型的开发机构和论文作者机构分别记录。

## 评议候选

| 维度 | 低分（1–4） | 中分（5–7） | 高分（8–10） |
| --- | --- | --- | --- |
| 严谨性 | 主张或指标模糊，主要混杂因素没有对照 | 可测试，有部分对照，仍有限定条件 | 主指标和证伪条件清楚，关键对照能区分竞争解释 |
| 原创性 | 关键操作已覆盖，可检验的差异很小 | 有明确的设置、操作或解释差异 | 已核对的近邻工作都留下了同一个实质缺口 |
| 重要性 | 即使成立，也很少改变结论或决策 | 能回答一个具体子领域的问题 | 能解释普遍现象，或影响一类方法的选择 |

分数用于同一任务中的相对比较。给出依据、主要扣分点以及最能改变判断的一项补查或对照。原创性证据不足时先标「待评」。
