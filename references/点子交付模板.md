# 点子交付模板

用户要研究点子、算法或方案时，**在聊天里直接给答案**，不发 md 文件（用户明确要文件时除外）。本模板来自本 skill 两次实际交付：免训练的 FCD（失败对比解码）和需要训练的 FBNO（失败反馈盲负例优化）。

## 开头一句

先说明三件事：点子叫什么、属于哪类（免训练 / 需要训练 / 分析类）、查新深度和数字的性质。

> 需要训练的算法我选了 **[名字（中文全称）]**，它是 [一句话定位]。查新时最接近的 [N] 篇论文都读了全文，没找到相同的做法。还没跑过实验，下面的数字都是预测或估算。

## 八个部分（顺序固定）

### 1. 一句话

一到两句：做什么 + 为什么要这么做。

> 写法：把 [某个信息] 抹掉 / 加上，[做什么操作]，然后 [怎样更新或解码]。这样做是为了让 agent [解决的具体失败现象]。

### 2. 算法

- **记号：** 每个符号一句话定义。
- **核心公式或目标函数：** 用 LaTeX。需要训练的写损失；免训练的写解码规则。
- **伪代码：** 训练方法写「每轮训练的步骤」；免训练方法写「每一步解码的流程」。用代码块，编号。
- **超参范围：** 每个超参给一个范围或默认值。
- **边界情况：** 例如「没有正例时改用 unlikelihood」。

### 3. 为什么有效

- **已知现象：** 1–2 个，带论文链接，最好带数字（来自论文原文）。
- **原理：** 机制上为什么这个操作能解决那个现象。
- **安全阀：** 为什么不会误伤（例如「环境核实保证不会误伤合理的重复」）。

### 4. 和已有工作的区别

- 列最接近的 3–5 篇，每篇一条：「[编号 + 简称] 做的是 [……]。我们不同在 [……]。」
- 标出**思想上最接近的**那篇，以及**最关键的基线**。
- 大公司的工作单独标（按署名）。
- 近半年的工作和更早的经典分开。

### 5. 实验

| 项 | 写什么 |
| --- | --- |
| 环境 | 先用什么合成环境调参，主实验用什么基准 |
| 模型 | 规模从小到大，复核模型 |
| 基线 | 含最关键的那篇；含「简单方法」基线（如重复惩罚、在提示里列出失败动作） |
| 消融 | 每个组件去掉一次；关键假设换掉一次（如随机负例代替核实负例） |
| 指标 | 主指标 + 机制指标（能证明「是因为这个原因」的那个量） |
| 时长 | 每组实验和总耗时，标「估算」 |

### 6. 预测与证伪

- **预测：** 带数字，对主指标和机制指标各至少一条。
- **证伪：** 写「出现以下任一情况，这个想法就不成立」，至少三条：
  - 不比最简单的基线强（差距在种子方差以内）
  - 关键组件换成随机或去掉后效果一样
  - 机制指标变了但主指标不变（或反过来）

### 7. 打分与风险

- **打分：** 严谨性 X、原创性 Y、重要性 Z（每项 1–10）。写明最低那项的扣分原因。
- **风险：** 3–5 条，至少包括：实现前提（如需要 logits、需要确定性环境）、小模型可能根本不读反馈、撞车风险、损失稀疏或信号弱。每条风险尽量配一个「第一步先测什么」。

### 8. 备选

一段话：名字、做法、和主选的关系、打分、查新深度（全文 / 只看了摘要）。

## 写法要求

- 全部在聊天里给，用小标题和列表，公式用 LaTeX，伪代码用代码块。
- 论文链接用 `[编号](https://arxiv.org/abs/编号)`，每个都要核实过能打开。
- 每个数字标明：来自论文、实测、预测或估算。
- 不写「本方法将显著提升」这类空话，只写带阈值的预测。
- 用户说「换个」：重新走第 3–6 步，不是改个名字。
- 用户说「最好有算法」「需要训练的」：必须有第 2 部分的公式和伪代码。

## 两次实际交付的骨架对照

| 部分 | FCD（免训练） | FBNO（需要训练） |
| --- | --- | --- |
| 一句话 | 解码时对比「完整历史」和「把失败观察遮掉的历史」下的 log 概率，放大失败反馈的作用 | 把失败反馈抹掉让模型生成动作，经环境核实会失败后，在完整历史下压低它的概率 |
| 算法 | 对比解码 + JSD 门控 + 可信度约束，只作用于动作 token | GRPO/GiGPO 损失 + λ·DPO 式失败反馈盲负例损失；无正例时用 unlikelihood |
| 最接近工作 | IHDec 2606.29960（骨架几乎一样，但抑制低权限工具内容）；EG-CFG 2506.10948；CAD 2305.14739、AdaCAD 2409.07394；RIR 2609.18304 | SSFO 2508.17225；CVT-RL 2606.05263；SERL 2605.19447；EFCA 2608.08255、2610.25957（最关键基线） |
| 实验 | 合成环境调参 → ALFWorld 134 局；Qwen3 1.7B/4B，Llama-3.2-3B 复核 | 合成环境 → ALFWorld seen/unseen（GiGPO 框架）；Qwen3-0.6B/1.7B |
| 预测 | 重复失败下降 ≥ 40%，成功率 +3–8 点 | 比 GiGPO 高 3–6 点；重复失败率降 50% 以上；JSD 随训练上升 |
| 打分 | 7 / 6 / 7 | 7 / 6 / 7 |
| 备选 | FLC（失败账本压缩），7/5/6 | EIR-PO（注入错误前缀的 RL），6/5/6，只做了摘要级查新 |

完整的 FBNO 走流程示例见 [examples/FBNO_全流程示例.md](../examples/FBNO_全流程示例.md)。
