# FBNO 示例

本示例演示如何把「代理可能忽略失败反馈」变成一个可检验的训练方案。查新状态为证据不足，实验状态为未运行。以下阈值是演示用的预设值。

## 1. 收敛主张

在带确定性反馈的合成任务中，对基线训练加入失败反馈盲负例优化（FBNO），预计能减少代理在收到失败反馈后再次选择同一无效动作的概率，同时保持任务完成率。

先定义「重复失败率」。分母是刚观察到失败、失败动作仍可选且至少还有一个替代动作的决策点，分子是下一步重复同一失败动作的次数。提前退出按任务未完成计入完成率。

## 2. 查新和对照

用「无效动作惩罚」「失败反馈训练」「有无上下文生成偏好对」「代理重复失败动作」及对应英文术语查找相邻方法。逐篇核对方法和附录，确认是否同时具备「遮蔽失败反馈生成负例」「环境核验动作失败」「在完整历史下训练」这三个操作。完成全文核对后再判断差异是否成立。

| 条件 | 用途 |
| --- | --- |
| 原训练目标 | 测量基线 |
| 原目标加重复动作惩罚 | 检查直接惩罚是否足够 |
| 原目标加经核验的随机负例 | 检查收益是否来自加入任意负例 |
| 原目标加遮蔽反馈生成的负例 | 检验 FBNO 的额外作用 |

## 3. 方法和最小实验

用合成的「箱子找钥匙」环境产生含失败反馈的历史。令 $H_t$ 是完整历史，$\widetilde H_t$ 是用占位符替换失败反馈的历史。令 $a^+$ 和 $a^-$ 分别为在同一状态核验通过的有效动作和失败动作。冻结一份参考策略 $\pi_{\mathrm{ref}}$。用完整历史对动作序列计分，并将偏好损失加到原目标。

$$
\begin{aligned}
g_\theta(a,H_t) &= \log \pi_\theta(a\mid H_t)-\log \pi_{\mathrm{ref}}(a\mid H_t),\\
L_{\mathrm{FB}} &= -\log\sigma\bigl(\beta[g_\theta(a^+,H_t)-g_\theta(a^-,H_t)]\bigr),\\
L &= L_{\mathrm{base}}+\lambda\,\operatorname{mean}(L_{\mathrm{FB}}).
\end{aligned}
$$

```text
每个训练批次：
  用当前采样策略收集轨迹，计算原训练目标
  从含失败反馈的决策点中抽取最多 K 个状态
  对每个状态：
    在遮蔽历史下生成 m 个候选动作
    重放到同一状态，核验候选是否失败
    将已核验失败动作与同状态的有效动作配对
  若存在配对，在完整历史下计算并平均偏好损失
  若无配对，仅用原训练目标更新
```

可以从 $m=2$、$K=8$、$\lambda=0.1$、$\beta=0.1$ 试起。这些是未实测的起始设置。在验证集比较选项后锁定超参。随机负例对照从同一状态的合法动作中抽取，使用相同的失败核验和尽可能匹配的负例预算，并报告实际配对数量。

先冻结基线模型，用成对历史检查遮蔽反馈是否改变动作选择，例如比较两种历史下同一动作的选择率，以及候选动作分布的 Jensen–Shannon 散度。同步验证自动判分和环境重放。若能测到有意义的信号，再用相同的数据切分、模型、训练步数和测试种子运行四个条件。

| 追加消融 | 检查什么 |
| --- | --- |
| 保持遮蔽与采样，取消失败核验 | 核验是否防止把有效动作当成负例 |
| 保持核验，改从完整历史采样 | 训练收益是否依赖遮蔽失败反馈 |
| 用等长度占位或遮蔽等量的无关反馈 | 是否只是输入长度或占位符造成的变化 |

## 4. 预测与判定

预测 FBNO 相对重复动作惩罚组至少降低 5 个百分点的重复失败率，任务完成率下降不超过 2 个百分点。若置信区间排除了这两个目标中的任意一个，则反对该预测。若区间仍跨过阈值，则记为无法判断。只有相对随机负例组也观察到可区分的改进，才将结果作为遮蔽反馈有额外价值的证据。先报告小环境中的结果，再用不同的合成任务测试外推范围。

## 5. 风险与下一步

- 遮蔽反馈可能同时丢失决定有效动作的信息。用等量无关反馈的对照检查。
- 失败反馈在某些任务中可能和状态变化相关。失败动作在历史中出现过，仍须在当前状态重放核验。
- 负例稀疏时，报告合格配对率，再决定是否加大采样或只在反馈明确的状态上验证。
- 备选是重放带失败反馈的前缀，让策略直接练习恢复。此方向需要单独查新和验证。
