# 预测表

对应 SKILL 第 9、10 步。**跑之前**填「预测」各列，**跑之后**填「结果」各列。写不出预测的实验不跑。

一句话结论：

| 编号 | 日期 | 实验（只改的因素） | 我的预测（带数字或方向） | 理由 | 把握 | AI 的预测 | AI 的理由 | 实际结果 | 意外？ | 我为何那样预测 / 实际为何如此 | 下一步 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| E1 | | | | | % | | | | | | |
| E2 | | | | | % | | | | | | |
| E3 | | | | | % | | | | | | |

## 填写规则

- 「会有影响」不算预测；要写成「X 至少下降 40%」「A 条件高于 B 条件」。
- 人先写，AI 后写；AI 写预测时不要给它看你的预测。
- 两份预测不一致：开跑前讨论一次，把讨论结论写进「理由」。
- 意外时，「下一步」写一个新问题或新实验，不要只写「重跑」。
- 放大检验也用这张表，在「实验」列注明规模档位。
