# AI 辅助做研究写顶会论文

一个给 AI 助手用的 skill：带着你从定领域、出点子、查新打分，到收成一句可证伪的结论、跑小实验、写成能投稿的短文。目标会议可以是 ICML、NeurIPS、ICLR 或同级会议。

AI 负责检索、出点子、跑实验、给批评和预测；选题、判断、理解和终稿由人来做。

方法整理自 Vuk 武克（Vuk Rosić）四条公开讲解视频，共 36 条观点、9 处说法冲突。每一步都标了出自哪条视频。视频里的招生内容和未核实的说法单独隔离，不进入方法。

## 快速开始

**安装：** 把本仓库放进支持 `SKILL.md` 的技能目录，文件夹命名为 `ai`。也可以让当前助手直接读取根目录的 `SKILL.md`。

**找研究点子：**

```text
按「AI 辅助做研究写顶会论文」这个 skill，帮我在 [智能体] 方向找一个研究点子。
目标 ICML 2027，算力是一张 24GB 卡。
要有算法，需要训练的。直接在聊天里给答案。
```

助手应依次检索近半年文献、出点子、查新（yes/partly/no + 最接近论文 + 缺口）、打分，然后按八段式直接给出：一句话、算法、为什么有效、和已有工作的区别、实验、预测与证伪、打分与风险、备选。

**已经有题目，要推进实验：**

```text
我的一句话结论是「……」，只看 [部件]。
按这个 skill 帮我设计最小对照实验，先写预测表，不要写代码。
```

**写作阶段：**

```text
这是我的研究短文草稿。按 skill 第 13 步的五项清单检查，列出最该补的 3 件事，不要改写全文。
```

## 流程一览

| 步骤 | 做什么 | 出处 |
| --- | --- | --- |
| 0 | 摆正心态：马拉松、允许迷茫、先走起来 | 视频3 |
| 1 | 自己定领域，让 AI 找往届相近论文，自己读 | 视频3 |
| 2 | 读完就动手，不要只读不写 | 视频3 |
| 3 | 用短提示并行要一批点子 | 视频1、2 |
| 4 | 按算力和三条好问题标准初筛 | 视频1、3 |
| 5 | 强制查新：yes/partly/no、最接近论文、缺口 | 视频1、2 |
| 6 | AI 当 ICML 审稿人打分并追问；人决定做哪些实验 | 视频2 |
| 7 | 只选一个，收成一句可检验的结论 | 视频4 |
| 8 | 把实验缩成能很快迭代的最小对照 | 视频1、3 |
| 9 | 每个实验开跑前先预测 | 视频1、3 |
| 10 | 意外就是课题；追问为什么，抓矛盾 | 视频1、3 |
| 11 | 让 AI 保持专注：一句话汇报，可并行 | 视频2、4 |
| 12 | 先小规模成立，再做放大检验 | 视频4 |
| 13 | 每天写，先要反馈，用五项清单补短文 | 视频4 |
| 14 | 在聊天里直接交付答案 | 使用偏好 |

## 规矩

- 不编造论文、编号、作者、会议接收结果或实验数字；没实测的数字标「预测」或「估算」。
- 查新只看了摘要时明确说明；「没找到」不等于「没人做过」。
- 文献默认看近半年；大公司的工作按署名单独标出。
- 研究点子在聊天里直接给答案，不先甩文档。
- 招生、定价、职业承诺不进入方法。
