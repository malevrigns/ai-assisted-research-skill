# AI 辅助做研究写顶会论文

一个用于机器学习研究的 Agent Skill。从你正在做的环节开始，支持选题、查新、实验设计与复现、结果分析和论文审阅。

## 快速开始

把仓库内容放入客户端的技能目录，文件夹命名为 `ai-assisted-research-skill`。也可以让助手直接读取根目录的 [SKILL.md](SKILL.md)。

说清当前任务即可。助手会加载 [提示词库](references/提示词库.md) 的对应流程，按顺序执行并核对交付。也可以直接指定编号，例如「按 R06 查新」。

| 场景 | 可以这样问 |
| --- | --- |
| 选题 | 帮我找一个适合单张 24 GB 显卡验证的机器学习研究点子。先查最接近的论文，再给主张、基线和证伪条件。 |
| 查新 | 对比这项方法和最接近的论文。检查方法、实验与附录，写清哪些内容已覆盖。 |
| 实验 | 我已有主张和基线。帮我设计最小对照，先写主指标、预期和证伪条件。 |
| 写作 | 按主张逐条检查这份草稿的证据，列出最该修改或补实验的三处。 |

## 仓库内容

- [SKILL.md](SKILL.md) 提供工作流和交付要求。
- [references/](references/) 提供查新与评分、实验设计、研究取舍、点子交付和可复用提示。
- [templates/](templates/) 提供结论卡、预测表、研究日志和短文骨架。
- [FBNO 示例](examples/FBNO_全流程示例.md) 演示如何从一个假设走到损失函数、伪代码、消融和可证伪的实验方案。
