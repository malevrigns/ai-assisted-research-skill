# AI 辅助做研究写顶会论文

一个给 AI 助手用的 skill：带着你从定领域、出点子、查新打分，到收成一句可证伪的结论、跑小实验、写成能投稿的短文。目标会议可以是 ICML、NeurIPS、ICLR 或同级会议。

AI 负责检索、出点子、跑实验和给批评；选题、判断和终稿由人来做。

## 快速开始

把本仓库放到支持 `SKILL.md` 的技能目录，文件夹命名为 `ai`。也可以让当前助手直接读取根目录的 `SKILL.md`。

在对话里说明目标会议和大致方向，例如「按这个 skill，帮我找一个智能体方向的研究点子」，助手应依次完成查新、打分，并给出一句结论、最小实验和证伪条件。

## 这个 skill 要求什么

1. 先定领域，读往届论文，尽快动手，不要只读不写。
2. 用多个独立的 AI 出点子，但先查新再喜欢上某个点子。
3. 对每个点子回答「做过 / 部分做过 / 没做过」，并打开最接近的全文核对。
4. 按严谨性、原创性、重要性打分，只选一个点子，收成一句可被推翻的结论。
5. 把实验缩到能很快迭代；每次开跑前先预测；先小规模，再放大。
6. 让 AI 保持专注，不要代写整篇论文。
7. 每天写一点，用连贯、全面、解释清楚、站得住脚、最好是新的这几项补短文。

完整步骤、需要同时遵守的几处张力，以及引用核实等规矩，见 [SKILL.md](SKILL.md)。

## 来源与说明

方法步骤整理自公开讲解中「用 AI 做 AI 研究、写顶会论文」的操作流程，并补上了执行时必须遵守的纪律：引用要核实、未跑过的实验数字必须标明是预测或估算、宣传内容不当作方法依据。

本仓库不构成对任何课程、社群、论文或实验结论的背书。
